# 🧮 Calculator

A simple **console-based Calculator** developed in **C** for performing basic arithmetic operations such as addition, subtraction, multiplication, and division.

![C](https://img.shields.io/badge/Language-C-blue?style=for-the-badge\&logo=c)
![GCC](https://img.shields.io/badge/Compiler-GCC-red?style=for-the-badge\&logo=gnu)
![Status](https://img.shields.io/badge/Status-Completed-success?style=for-the-badge)

---

## ✨ Features

| Feature               | Description              |
| --------------------- | ------------------------ |
| ➕ **Addition**        | Add two numbers          |
| ➖ **Subtraction**     | Subtract two numbers     |
| ✖️ **Multiplication** | Multiply two numbers     |
| ➗ **Division**        | Divide two numbers       |
| 🚫 **Zero Check**     | Prevent division by zero |
| 🚪 **Exit**           | Close the calculator     |
