
# 📚 Library Management System

A simple **Library Management System** built using the **C programming language**. This project is designed as a beginner-friendly mini project to practice fundamental C programming concepts.

## ✨ Features

* 📖 Add new books
* 📋 Display all books
* 🔍 Search books by ID
* 📤 Issue books
* 📥 Return books
* 🗑️ Delete books
* ✅ Check book availability
* 🚪 Exit the system

## 🛠️ Technologies Used

* **C Programming Language**
* `stdio.h`
* `string.h`

## 📌 Concepts Used

This project demonstrates:

* Variables and data types
* Conditional statements
* `switch-case`
* Loops
* Functions
* Arrays
* Strings
* Structures (`struct`)
* Searching
* Basic data management

## 🚀 How to Run

### Clone the repository

```bash
git clone https://github.com/your-username/library-management-system.git
```

### Go to the project directory

```bash
cd library-management-system
```

### Compile the program

```bash
gcc main.c -o library
```

### Run the program

**Windows:**

```bash
library.exe
```

**Linux/macOS:**

```bash
./library
```
