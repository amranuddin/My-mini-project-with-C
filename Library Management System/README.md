# 📚 Library Management System

A console-based **Library Management System** developed in **C** for managing books, issuing and returning books, and tracking book availability.

![C](https://img.shields.io/badge/Language-C-blue?style=for-the-badge\&logo=c)
![GCC](https://img.shields.io/badge/Compiler-GCC-red?style=for-the-badge\&logo=gnu)
![Status](https://img.shields.io/badge/Status-Completed-success?style=for-the-badge)

---

## ✨ Features

| Feature             | Description                                 |
| ------------------- | ------------------------------------------- |
| 📖 **Add Book**     | Add a new book to the library               |
| 📋 **View Books**   | Display all books                           |
| 🔍 **Search Book**  | Find a book using its ID                    |
| 📤 **Issue Book**   | Issue an available book                     |
| 📥 **Return Book**  | Return an issued book                       |
| 🗑️ **Delete Book** | Remove a book from the system               |
| ✅ **Availability**  | Track whether a book is available or issued |

## 🚀 Getting Started

### Prerequisites

Make sure **GCC** is installed on your system.

### Clone the Repository

```bash
git clone https://github.com/your-username/Library-Management-System.git
cd Library-Management-System
```

### Compile

```bash
gcc main.c -o library
```

### Run

**Windows**

```bash
library.exe
```

**Linux / macOS**

```bash
./library
```
